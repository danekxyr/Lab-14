# Лабораторная работа № 14

* **Студент:** Пылинский Даниил Максимович
* **Группа:** ПИ 1-1
* **Тема:** Строки и безопасный ввод

## Назначение файлов проекта

* **`main.c`** — безопасное чтение строки в буфер `char text[32]` через `fgets`, удаление символа перевода строки `\n` с помощью `strcspn`, проверка ограничения длины (не более 30 байт) и вывод строки с её длиной.
* **`self.c`** — безопасный ввод строки с подсчётом количества цифр (`'0'..'9'`) и обычных пробелов (`' '`) с игнорированием остальных символов.
* **`tests.txt`** — протокол обязательных и собственных граничных тестов, включая пошаговую трассировку переменных для первого примера.

## Ограничения входа

* Вводятся однобайтовые символы (латинские буквы, цифры и пробелы), максимальная допустимая длина строки — `30` символов (буфер на `32` байта вмещает 30 символов, `\n` и завершающий `\0`).
* При вводе `31` и более символов заполненная часть имеет длину `31`, и программа завершается с сообщением `Too long`.

## Команды сборки (PowerShell / Bash)

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o lab14
gcc -std=c11 -Wall -Wextra -Wpedantic self.c -o self
```
